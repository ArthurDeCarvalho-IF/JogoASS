# Jogo de A.S.S.

Repositório para o projeto de jogo da matéria Ambiente, Saúde e Segurança, do Instituto Federal do Amazonas _Campus_ Manacapuru.

## Objetivo

Na parte mais técnica: desenvolver um jogo de aventura e exploração que consiga integrar:

- Narrativa;
- Mecânicas de progressão;
- Elementos do folclore amazônico;
- Sistema dinâmico de restauração ambiental.

## Tecnologias Utilizadas

| Função                   | Tecnologias             |
| ------------------------ | ----------------------- |
| Estilização (Site)       | CSS, SCSS               |
| Programação (Site)       | JavaScript, TypeScript  |
| Gerenciamento do projeto | Git, GitHub, GitHub CLI |

## Estrutura de Pastas

| Nome            | Descrição                                                  |
| --------------- | ---------------------------------------------------------- |
| `/concept-arts` | Artes conceituais de personagens e cenários                |
| `/gdd`          | Todas as versões do Game Design Document (GDD)             |
| `/sons`         | Contém efeitos sonoros e trilhas sonoras                   |
| `/sprites`      | Imagens que serão usadas no projeto                        |
| `/relatorios`   | Documentos semanais que servirão como avaliação individual |

## Como adicionar arquivos ou modificá-los (via terminal)

1. Faça o pull para garantir que está na versão mais recente: `git pull origin main`
2. Crie seus arquivos nas pastas correspondentes.
3. Se criar uma pasta nova, adicione um arquivo `.gitkeep` se ela estiver vazia.
4. Envie suas alterações:

- `git add .` (O ponto significa a pasta atual no terminal).
- `git commit -m "descrição da alteração"`.
- `git push`.

###### _Obs.: é possível utilizar o app para computador "GitHub Desktop"._
